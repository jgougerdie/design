Proposal Pipeline

The fixed sequence for turning a pasted Upwork job post into a submitted proposal — built from every edge case worked out the hard way, so none of it has to be re-decided by hand again.

8 stages 3 guardrail sets rev. 2026-08-29

The pipeline

Runs top to bottom on every job post. A stage is never skipped — if it doesn't apply, it resolves instantly and moves on.

00:01

Intake

A job post is pasted. This alone triggers the full pipeline — no separate request needed.

00:02

Screen

Produce Match, Decision, and Reason in one line each.

GO  QUALIFIED GO  NO-GO

Standing rule — a real gap is never the end of the screen. Find the honest workaround (live sample-cut, adjacent transferable work, freshly generated proof) before landing on NO-GO. Reserve NO-GO for when no honest path exists at all.
00:03

Name the buyer's pain

One sentence — what's actually broken or at risk for them, not a restatement of the task list.

00:04

Check assets

Verify real portfolio content before recommending it — open the file, extract frames, watch it. A filename is not proof of content.

If nothing matches, work down the ladder. Stop at the first option that applies:

  1. A real, verified portfolio piece that matches.
  2. The job supplies the buyer's own footage/assets — offer a fast live sample-cut from those instead of a pre-made sample.
  3. No match, no buyer assets — take a stock clip as a style reference only, derive a generation prompt from it, and produce fresh original footage on a sustainable free-credit generator (Kling, Pika). Label it honestly as AI-generated.
Hard line — stock or found footage is never sent as "my work," disclosed or not. Only a verified original piece, a live sample cut from the buyer's own assets, or freshly AI-generated content counts as an attachable sample.
00:05

Write the cover letter

  • Opens with "Hi," — unless the post itself mandates an exact opening phrase (e.g. a screening trap phrase), which overrides and comes first.
  • Pain, approach, proof, close — no greeting-as-filler beyond the opener.
  • No pricing anywhere in the letter body.
  • No placeholders or brackets left for later. Commit to a real number or claim. The only exception: a fact only the freelancer can verify (years of experience, real availability, a real link) — ask for that specific fact instead of guessing.
  • Delivered whole, in one message. Never in pieces.
00:06

Price it

Hourly — default $25/hr; bid toward the top of the posted range for a strong, high-quality buyer.

Fixed — one concrete number, sized to scope and the visible bid range. Milestones only when they genuinely reduce delivery risk.

Always stated separately for the platform's own price field — never folded into the letter.

00:07

Screening Q&A

Only becomes its own labeled section when the post has an actual formal Screening Questions field.

A buyer's inline "please include X, Y, Z" in the body text is not that field — fold those answers directly into the letter instead.

00:08

Package the rest

Everything after the letter splits into two short tiers — bullets only, no paragraphs, skip a tier if it's empty.

⚡ ACTION NEEDED

  • Bid / milestone amount
  • Any fact only the freelancer can supply
  • Attachment to send, if any

📋 FYI — no action

  • Buyer risk signals
  • Competition context
  • Pricing rationale

Guardrails

Not steps — constraints that apply at every stage, all the time.

GuardrailWhat it means in practice
Never fabricateNo invented years of experience, clients, metrics, tools not actually used, or turnaround claims. If a real fact is missing, ask for it by name — don't infer, don't guess.
Don't re-askOnce told a sample, fact, or asset genuinely doesn't exist, that stands. Move to the next rung of the gap-filling ladder instead of asking again.
Verify before recommendingAny existing file (Drive, uploads) gets opened and actually reviewed — frames pulled, content watched — before it's called a match or a mismatch.
No cross-session memoryEach session starts cold. The proposal-engine profile is the source of truth for verified facts; anything not in it gets asked for, never assumed.
