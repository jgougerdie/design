Stage by stage

What each stage actually checks

The rules an automation needs to encode, not just the step names.

T+00

Trigger automatable

A saved Upwork search fires on new postings under Video Editing / Video Production, filtered to social/short-form keywords (Instagram, TikTok, reels, captions).

T+01

Screen automatable

Run the buyer and the scope against the rubric below. Payment/phone verification and a low budget are never disqualifying on their own — a repeat-posting content-mill pattern, a positioning mismatch, or an unworkable scope are.

T+02

Draft automatable

Buyer pain first, then approach, proof, pricing, close — never open with "excited" or a credential dump. The rubric and voice rules are already written down; an LLM step can apply them directly.

T+03

Price blocked

The rate that's actually quoted ($25/hr) was found by accident inside a stray Drive doc, not read from anywhere the draft step can rely on. Every run risks quoting a placeholder instead.

T+04

Match portfolio automatable

Search Drive for samples tagged to the job's platform and format — a social-cut, a caption sample, a vertical-frame piece — rather than reaching for whatever's most recent.

T+05

Check sharing blocked

Matched files default to owner-only. Today someone has to flip each one to link-viewable per job, after the letter is already drafted — the exact repeat motion this workflow exists to remove.

T+06

Human review needs Javad

Rate posture on a first job with a new buyer, tone, and any wording that reads generic are calls only Javad makes — the automation should stop here and hand over a draft, not push past it.

T+07

Submit needs Javad

No Upwork write access exists in this pipeline. The line ends at a ready-to-paste draft, not a sent proposal.

Screening rubric

Go / Qualified Go / No-Go

The three-way call the screen stage has to reproduce every time.

VerdictCall it whenExample seen this week
Go Strong creative fit, clear problem, credible delivery path, no credibility gap. —
Qualified Go Strong core fit with a manageable gap — new/unproven buyer, missing footage details, ambiguous scope. Social video job, Netherlands buyer, account created same day, 0% hire rate, but scope and pay band were reasonable.
No-Go Mismatched skills, unsafe work, or — as important — a scope/pay pattern that undercuts the studio's own positioning, even when the buyer is legitimate. "AI-Generated Content" editor at $3/task: a verified, well-reviewed buyer running the same posting on repeat as piecework, paying roughly a fifth of standard rate.

Fixes before it can run unattended

What's actually blocking automation

Rate has no single source

The number the draft stage needs was pulled from a portfolio doc that happened to mention it — not a field the automation could rely on existing.

Keep one settings field (a Sheet cell, a Doc, a config value) that is the rate. The draft stage reads it; nothing else guesses it.

Portfolio sharing resets to private

Every matched sample defaults to owner-only, so someone has to open sharing by hand after the letter already names the files.

Keep one evergreen "Portfolio — Public" folder, permanently set to link-viewable, with files named and tagged by format up front. Matching then never touches permissions.

No path to actually submit

Nothing in this pipeline can post a proposal on Upwork — that's a real gap, not an oversight to design around.

Stop the automation at a ready-to-paste draft delivered to Javad, every run. Don't build toward auto-submit until there's real write access.

Suggested build

How this becomes a running automation

A shape for n8n or Make, given the stages above.

Trigger
Scheduled poll of the saved Upwork search (RSS or feed watch) — T+00.
Screen
LLM node running the rubric above; branches to stop on No-Go, continues on Go / Qualified Go — T+01.
Draft
LLM node writing the letter, reading rate from the settings field and sample links from the portfolio catalog — T+02–05.
Hand-off
Deliver the draft to Javad (Slack message or email), not to Upwork — T+06.
Close
Javad reviews, adjusts rate posture, pastes and submits by hand — T+07, permanently manual until submit access exists.
